# 📚 CosmosLibrary

CosmosLibrary is a collaborative online library management system developed as a university team project.

The project provides a web-based platform for managing library resources and interactions through a dynamic frontend and a Django-based backend.

> **This project was developed collaboratively by a team of five students. I contributed to the development of the project as one of the team members.**

---

## 🎯 Project Overview

CosmosLibrary is designed to provide an online environment for managing and accessing library resources.

The system combines a dynamic web interface with a backend built using Django REST Framework to handle application logic and data.

The project demonstrates how different web technologies can work together to build a complete web application.
